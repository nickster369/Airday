# Airday

Know what airs on which day. Personal tracker for anime, TV and movies. Static site: no build step, no server.

## Files
- `index.html`: the whole app
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`: home-screen app icon and name

## Live data
- Anime: AniList (no key)
- TV: TVmaze (no key)
- Movies: TMDB (free key, entered in the app's Settings and stored on the device only)

## Your data
Saved in the browser on each device (localStorage). Use Settings > Download backup now and then.
Never commit a backup file to this repo; GitHub Pages repos are public.
